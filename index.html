CẤU HÌNH METERED OPEN RELAY (TURN SERVER)

Khi chơi qua các mạng Wi-Fi khác nhau, 4G, hoặc bị kẹt sau tường lửa NAT/CGNAT, WebRTC cần TURN Server có xác thực để chuyển tiếp dữ liệu xuyên NAT.

Nhập tên App bạn đã tạo trên metered.ca (ví dụ: mygame.metered.ca)
Metered cung cấp 50 GB băng thông TURN miễn phí mỗi tháng.
ℹ️ Chưa kiểm tra. Nhập thông tin và bấm "Kiểm Tra Kết Nối".
📖 Xem nhanh cách lấy API Key miễn phí (3 bước)
  1. Truy cập metered.ca/tools/openrelay và đăng ký tài khoản miễn phí.
  2. Tại trang Dashboard, bấm Create App (đặt tên bất kỳ, ví dụ: cungdau).
  3. Vào app vừa tạo, copy App Name (hoặc Domain) và API Key rồi dán vào đây!

* Mẹo: Khi bạn tạo phòng và bấm "🔗 Copy Link Mời", link sẽ tự đính kèm cấu hình để bạn bè vào ngay mà không cần cài đặt!

CÀI ĐẶT APP BẮN CUNG VÀO ĐIỆN THOẠI

Game hỗ trợ chuẩn Progressive Web App (PWA), cho phép cài đặt trực tiếp lên màn hình điện thoại như ứng dụng tải từ CH Play / App Store (mở toàn màn hình, tự động khóa ngang, không có thanh địa chỉ web, chơi siêu mượt!).

  1. Mở link game bằng trình duyệt Google Chrome hoặc Cốc Cốc trên điện thoại Android.
  2. Bấm vào biểu tượng dấu 3 chấm dọc (⋮) ở góc trên bên phải màn hình.
  3. Chọn "Cài đặt ứng dụng" (hoặc "Thêm vào Màn hình chính").
  4. Bấm "Cài đặt" xác nhận. Biểu tượng game sẽ lập tức xuất hiện trên màn hình điện thoại của bạn!
  1. Mở link game bằng trình duyệt Safari trên iPhone hoặc iPad.
  2. Bấm vào nút Chia sẻ (Share) biểu tượng ô vuông có mũi tên trỏ lên (📤) ở thanh công cụ dưới.
  3. Cuộn xuống danh sách tùy chọn và chọn "Thêm vào MH chính" (Add to Home Screen ➕).
  4. Bấm nút "Thêm" (Add) ở góc trên bên phải màn hình để hoàn tất!

Nếu bạn muốn xuất thành file .APK để gửi qua Zalo/Telegram hoặc cài đặt trực tiếp:

  1. Truy cập công cụ chính thức của Microsoft: PWABuilder.com
  2. Dán link web game của bạn vào ô và bấm Start.
  3. Bấm "Package for Stores" ➔ Android ➔ "Download Package (APK)".
  4. Bạn sẽ nhận được file APK sẵn sàng cài đặt trên mọi điện thoại Android!
